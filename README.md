## 📦 Installation

Clone the repository

```bash
git clone https://github.com/shilpa475/shilpa-portfolio.git
```

Move into the project

```bash
cd shilpa-portfolio
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Build production version

```bash
npm run build
```
